# Paradise Nursery Shopping Application

A responsive plant-shopping application built with React, Redux Toolkit, and React Router.

## Features
- Landing page with Paradise Nursery branding and Get Started button
- About Us page
- 18 houseplants across 3 categories
- Product cards with images, names, descriptions, prices, and Add to Cart buttons
- Redux Toolkit cart state
- Dynamic cart quantity badge
- Cart quantity increase/decrease and item deletion
- Per-item subtotals and overall total
- Continue Shopping and Coming Soon checkout actions
- Cart contents saved in browser local storage

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually http://localhost:5173).
